接入最终 NC 的去料仿真

FreeCAD 最终 NC 已在 CAMotics 从完整毛坯执行，0.025 mm 网格单核约 4.62 秒、512 MiB；尚需统一接口、几何精度验收与更多指令配置。

按原始 CAD 和公差验收

在已知坐标和基准下检查过切、欠切、孔径与孔位，计入计算误差；精度不足返回不可判定。纯几何不判定粗糙度。

接通错误反馈与真实回放

正常案例通过，故意改错的 NC 能被拒绝；把差异位置和原因反馈给规划，网页只展示实际保存的轨迹与材料。

展开开发内容

评估 CAMotics 多轴扩展路线

核查 NC 解析、刀具姿态、材料表示和去料算法中的三轴假设；比较源码二次开发、替换引擎与必要模块自研。

实现五轴 NC 与机床运动解释

按选定控制器和机床配置，从最终 NC 得到刀具相对毛坯的完整位置和方向；核对坐标、补偿、循环与旋转轴语义。

实现连续去料与独立几何验收

按变化的刀具姿态计算连续扫掠去料，保留真实剩余材料；补已建模刀柄 / 夹具干涉、计算误差和资源限额，再对照原始 CAD。

实现路线与五轴完成标准

先评估代码与最小原型，再选择扩展开源工具、接入其他引擎或自研必要模块；依据正确性、可维护性与本机资源预算决策。尚未承诺只修改现有两个项目就能完成五轴。

  • 先用已知短 NC 独立验证运动与去料，再接自动生成的五轴 NC；不能让生成和仿真的同一错误相互掩盖。
  • 最终 NC、配置和加工后几何一一绑定；原始 CAD 与要求保持独立。
  • 正常案例通过，错角度、错补偿、过切 / 欠切等反例能被检出；给出已验证的误差和范围。
  • 3+2 与连续五轴分别验收；动画、接口完成或旋转轴能动都不能代替五轴去料通过。
  • 本机只做受限的小模型与短路径；超预算列为未验证，不放宽公差凑通过。

落实到实际设备还需什么

  • 铭牌：制造商、完整型号、出厂年份、设备编号；控制器系统页：型号、软件版本及五轴 / TCP 选件。
  • 铣头型号及机床轴图：B/C 或 A/C、旋转中心、正方向、零位、轴序和限位；精确值来自设备手册 / 参数与标定。
  • 该设备已验证的 NC 样例、后处理说明、刀长 / 工件坐标及换头约定。

建议优先核对 G3020-5L 的旧款 iTNC530 + B/C 双摆头配置，作为首台真实设备候选。R0 仍先完成固定刀轴单孔；LinuxCNC 只保留独立开发参照，实际控制器 NC 语义和五轴后处理另行验证。

资源怎样从简单扩展到清单中的全部设备

R0：固定资源

单孔、单刀、单次装夹。先接通现成工具和几何验收。

R1：增加刀具与工序

逐项增加铣刀、孔 / 槽 / 台阶 / 型腔；增加刀具后再验证换刀、刀长和刀柄。

R2：启用旋转轴

同一参考结构上先做 3+2，再做连续五轴；分别验证坐标、运动、去料与干涉。

R3：覆盖实际设备

逐台映射清单中的控制器和参数；不同工艺另开能力分支，不能用五轴铣削通过代替车削、磨削等支持。

选设备的规则

  • 先按工艺类型分组，再在同一组中按轴系、控制器、资料完整程度和典型零件选择代表设备。
  • 首台优先选资料齐全、能完成简单单件、控制器语义与后处理可核对的设备。
  • 同类设备先复用参数和接口；不同控制器、机床结构或工艺分别增加适配和验收。

逐台记录支持程度

设备清单全部纳入长期覆盖范围。逐台记录：资料建档、工艺卡支持、NC 生成、NC 语义 / 运动、材料去除、几何验收和设备对照；非 NC 设备单列工序与验证方式。

已读取《设备 - 脱敏.xls》，先以 97 条记录整理覆盖清单；另一表 30 条描述均有对应项，不相加为 127 台。两款五轴型号的公开资料已查到，实际控制器、铣头与标定参数仍待核对。

资料与样本 · 建议

先要有代表性的资料，不需要先收集很多零件

当前不需要你先提供工艺卡或新文件：我们准备单孔测试输入，先接通参考流程。真实验证时再从现有图纸选 1 个简单单件，并补齐制造要求及共用资源档案。

01

现在：受控小试件

我们准备单孔测试工艺卡及正常 / 错误案例；标明合成参数、未经真实工艺审核和待补项。用参考配置开发接口与校验。

02

首轮真实验证：1 个单件

选择与当前能力匹配的简单零件，补齐要求、毛坯与装夹；使用同一套程序验证，而非按零件写专用代码。

03

每增加能力：补代表件

建议每类新特征先选 1–3 个真实件，并留独立验收件；这只是起步建议，不能据此宣称覆盖所有零件。

同类零件应只更换输入数据即可运行；出现新的加工特征、控制器、机床结构或验收要求时，再新增相应能力。

具体提供什么：每个零件的资料与共用设备资源

每个真实零件

  • CAD / CadQuery 和版本、单位；已有 STEP 可直接复用。
  • 制造要求：尺寸、公差、基准、粗糙度及对应孔 / 面；已有图纸或上游绑定结果均可，未绑定项单独标出。
  • 材料、实际毛坯形状 / 尺寸与装夹要求；没有既定方案时交规划选择，选定后才执行仿真。

设备资源建档一次，供多个零件复用

  • 一台参考或真实机床：型号、轴系、行程、控制器和版本；五轴再补旋转中心、方向及 TCP 等约定。
  • 可用刀具 / 刀柄、夹具及必要几何尺寸，坐标与刀长设置规则。
  • 如已有：经过确认的工艺卡、NC、手册和切削参数依据，用于独立对照。

我们准备接口、固定测试卡、受控试件与工具适配；你在真实验证阶段补充或确认实际要求和资源。真实工艺卡 / 已验证 NC 有则参考，不作为当前开工前提。

没有真实设备资料也能先做参考配置开发，但结果只代表参考配置；未知信息保持待补，不能推断成真实设备或材料已验证。

每个阶段，都用相同的完成标准。

  • 正常样例能通过，故意加入的错误能被发现。
  • 结果追溯到最终 NC、实际来料、刀具 / 装夹 / 设备配置和原始 CAD。
  • 给出计算精度与支持范围；精度不足或指令不支持时显式报告。
  • 每级先用小试件，再选匹配能力的真实单件；现有 71 份图纸作为验收案例库。

首轮使用固定测试工艺卡；工艺规划接口先定义，Agent 实现后置。真实加工工艺另行审核。

主线稳定后，再扩展毛坯、设备、材料和组装

更多毛坯

块料 → 已加工来料 → 更复杂的初始形状。

更多设备

同类设备换参数 → 不同控制器 → 不同五轴结构。

更多材料

逐种补充切削参数与适用依据；材料物理单独验证。

组装件

先验证组成单件，再增加配合、装配干涉与公差累积检查。

工具选择与技术依据
  • 毛坯形状影响去料几何；材料牌号、切削力、变形和粗糙度等另有验证要求。
  • FreeCAD 与 CAMotics 是起步工具。五轴编程与五轴去料分别列入二次开发 / 后端集成计划，源码扩展路径尚待可行性验证。
  • LinuxCNC 是可选的 NC 解释 / 机床运动验证工具；材料去除和最终几何验收需要另外实现或集成。
  • 本机开发保持小试件、短程序和受限资源；增加模型规模前先验证功能与误差。
