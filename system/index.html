几何推演是新增的程序：上一步的形状减去这一步要切掉的部分，得到这一步之后的目标形状，再给上面的面编号。它不出数控程序，也不调用仿真器。

2　结构化工艺计划

仍然只写“做什么”，不写“怎么做”。新增：加工中才存在的特征（工艺孔、夹持余量、留余量的面等）也要有编号和几何定义，格式修改方案待确认。

3　每个环节各有一处比对

每个环节单独测，输入用标准答案；出错时能知道是哪个环节、哪个工步。

环节一　几何识别
比什么 识别出的 CAD 对自带标签的 CAD
查不到 公差和粗糙度提取得对不对，要另外和图纸标注逐条对
环节二　几何推演
比什么 推演最后一步的形状对输入的 CAD
查不到 路线是否合理：装夹、基准、先后顺序
环节三　加工仿真
比什么 每个工步对该步的推演目标；最终对真实 CAD
查不到 车间能否达到，看经济精度和试切

4　接下来

几何推演：先在一个验收件上做最小验证→加工中特征的编号和计划格式→环节三接入每步目标形状→逐工步比对→需要 agent 的部分（最后做）

环节三已有的成果（计划 → 数控程序 → 仿真 → 两层检查）保留，等环节二能给出每步目标形状后再接。几何推演的最小验证正在进行，尚无结果。
