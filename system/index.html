展开输入输出、参数责任与检验边界

有限抽查三份真实板类工艺规程、共十三页；归纳工艺表达，尚未证明全部来料兼容。 四个一级模块保持，以下是模块 2 / 3 的设计定义。

ProcessPlan / 工艺意图

文档标识、版次和来源；原 CAD / 最终要求引用；工序 → 工步、装夹约束、工序间要求、依赖及条件分支；缺项与审阅状态。卡上明确指定的刀具和参数也是约束，不能擅自覆盖。

ExecutionPlan / 执行方案

已选择的分支与工步、实际来料、资源版本、工具几何、坐标变换和控制器语义、已确定参数及依据、执行与检验范围、前置条件；冻结后才能调用 CAM。

ProgramArtifact / 程序产物

最终 NC 与哈希、ExecutionPlan 引用、实际加工配置、工步与程序段的关联、适配器及 CAM / 后处理版本。FreeCAD Job 是内部产物。

VerificationResult / 检验结果

实际材料状态与来源、工步覆盖范围、最终 / 中间要求的逐项状态、IoU 等几何指标、未验证步骤和所缺外部证据；局部几何通过不能标记整张工艺卡完成。

谁负责确定参数？

  • 卡上明确规定：作为约束传递；修改须回到工艺规划或工艺师傅。
  • 资源提供：引用有版本的毛坯、设备、刀具、夹具及坐标配置。
  • 程序 / CAM 推导：记录依据、输入、规则或引擎版本；只能在已定义的工艺与能力范围内选择。
  • 无法确定：明确缺什么、影响哪步、交给谁处理；不得静默补默认值。

缺项怎么处理？

缺关键执行数据阻止对应 NC 生成；缺验收依据阻止对应质量判定。范围和前置条件必须明确，软件就绪与工艺批准分别记录。

仿真检验怎么报告？

  • 保留一坯一件 / 一坯多件及分支来源。首版仅实现单来料、单件、单装夹；批量拆分与复杂分支另行开发。
  • 上道实际剩料传给下道，换装夹保留坐标变换；原始目标 CAD 不用于重造中间材料。
  • 中间要求在对应工步检查，需要独立的要求或中间目标；最终结果始终对比原始目标 CAD。
  • 去毛刺、热处理、表面处理、人工检验等保留在工艺路线中；按当前能力标为未验证或关联外部证据，不能静默跳过。
  • 仅仿真部分工步时，明确范围与实际来料依据；后续依赖未满足，不能沿用错误材料继续或声称整件完成。

S1 的 genlaw.process-card.v0 是已执行固定脚本的参数记录，保持原文件。 新的 ProcessPlan / ExecutionPlan 为设计草案，尚无运行时解析器、校验器或迁移程序。

新零件来了，怎样扩展？

设计已定义 · 运行框架待实现

零件集合影响能力开发优先级；统一接口、原始数据与验收约定持续复用。

01 / 扩展约定

统一数据与流程

CAD、制造要求、工艺卡、资源配置和结果约定持续复用；格式变更带版本与迁移。

02 / 扩展约定

可替换的工艺与工具

编程、设备后处理、去料/成形、几何检验各有适配接口。FreeCAD 与 CAMotics 是首批实现。

03 / 扩展约定

可核对的支持范围

分别记录每一步支持的工序、坐标/指令、材料表示与精度；执行前检查整条链是否具备能力。

  1. 提取所需能力
  2. 匹配整链支持范围
  3. 复用配置或新增适配
  4. 运行新旧验收用例
新需求的扩展位置与验收条件
变化扩展位置怎样验收
新尺寸、孔位或数量使用已有能力，换 CAD 与工艺卡参数在已验证范围内运行；超尺寸、精度或资源预算明确返回缺项。
新的特征组合复用工序，增加编排与实际剩料交接验证顺序、换刀、坐标与工序间材料连续性。
新机床或控制器同类机床换配置；新轴链或 NC 方言增加适配器后处理与 NC 解释分别验证，不能仅换机床名称。
新工艺，例如车削增加编程、仿真后端及所需检验项沿用公共接口和结果页；新算法仍须开发与独立验证。
展开适配接口、能力声明与兼容约定

以下是模块 2 / 3 内部的扩展接口设计，不增加一级模块。现有 S1 的通用适配与能力匹配仍待实现。

GeometryPacket

cad_ref: 原文件、版本、哈希、单位、坐标；features / requirements: 稳定关联、原始标注与不确定项

引擎内部面编号不直接充当长期特征ID；转换后的网格不替换原始验收CAD。

ProcessPlan

document / provenance: 原卡、版次、页码/字段与引用资料；operations / steps: 工序、工步、目标特征、装夹约束、条件与依赖；requirements / resources: 最终与中间要求、资源约束、缺项及审阅状态

工艺意图与执行参数分开；原卡指定值是约束。保留条件分支与一坯多件语义，未实现类型明确返回不支持，禁止按零件编号分流。

ExecutionPlan

selected_steps / scope: 已选分支、工步、前置条件与执行/检验范围；resolved_config: 实际来料、资源版本、刀具、坐标、控制器和参数；parameter_provenance / decisions: 卡片约束、资源事实、推导依据和待决问题

由规则与资源在工艺约束内落实，冻结后交 CAM；缺关键数据或冲突时阻止对应执行，改变工艺意图须返回规划端。

ProgramArtifact

program_ref: 类型、方言、单位、文件哈希；resolved_config: 实际设备、坐标和刀长约定；provenance: 工艺卡、CAD、适配器、引擎与后处理版本；execution_plan_ref / step_map: 冻结方案及工步与程序段绑定

当前NC主线保留最终NC；非NC工艺将来使用明确的其他程序类型。FreeCAD Job 属于适配器内部产物。

MaterialState

geometry_ref: 实体/网格等表示与版本；frame / units / precision: 坐标、单位与表示误差；material_ref / parent_state / operation_ref: 材料、前一状态和来源工序；workpiece_lineage: 来料、分支、拆分及产出件来源

不同后端交换实际材料状态；格式转换声明误差和可支持范围，禁止从目标CAD重造中间材料。 一坯多件须记录拆分来源；当前 S1 只验证单来料单件。

VerificationResult

geometry_metrics: IoU、过切/欠切等指标与适用方法；requirement_results: 逐项通过、失败、未验证或不可判定；evidence_refs: 程序、材料、资源、比较器和回放来源；scope / coverage: 已执行工步、中间/最终检验、未验证步骤及外部证据状态

检验接口与引擎分离；局部精度不足时不能仅凭整体IoU判通过。 局部几何通过不等于整卡完成；缺中间或最终验收依据返回未验证/不可判定。

适配器分工

  • 工艺输入与执行方案解析：原卡/结构化意图 → 核对后的工艺 → 执行方案；参数保留依据，需改工艺时返回模块 1 / 工艺师傅
  • CAM adapter：冻结的执行方案 + CAD → 刀路/工艺程序；FreeCAD Job 是模块 2 内部产物
  • Machine / post adapter：刀路与资源 → 目标方言的最终NC；设备参数与后处理分开记录
  • Simulation adapter：最终程序与配置、实际来料 → 实际加工状态；保留控制器语义和材料来源
  • Verification adapter：原始 CAD / 最终要求、独立中间要求 + 实际结果 → 指标、逐项判定与工步覆盖

能力声明

只有编程、后处理、仿真和所需检验都在已验证范围内，才能声明该任务受支持；单步有能力不等于整链受支持。

  • 接口版本化，新增类型明确声明；旧卡片通过有记录的迁移保持可追溯。
  • 工艺特有参数使用有类型的扩展区，核心不假定只有铣削、Z向刀轴、矩形毛坯或单一网格。
  • 几何变换、单位、刀长与坐标由配置明确传递，不能依赖工具隐含默认值。
  • 统一输入输出不意味着统一所有物理模型；新增成形或材料物理允许独立求解器。
  • ProcessPlan / ExecutionPlan 细化原 OperationPlan 设计；旧 S1 参数卡须显式映射，迁移程序尚未实现。

目标是将修改集中在适配器、配置和必要的版本演进，并用测试证明兼容；不承诺任何新零件都无需算法开发或永远无需调整公共接口。

仿真检验

当前开发范围

按同一 NC 和配置从声明的实际来料去料，保存材料来源与工序间状态；在有独立依据时检查中间要求，最终对比原 CAD。报告已验证工步、未验证步骤和质量项；局部几何通过不代表整张工艺卡完成。

输入 / INPUT

nc_ref / execution_plan

模块 2 的同一份最终 NC、工步关联、执行和检验范围

machining_config / incoming_state

实际来料、刀具、装夹/坐标与控制器语义；多工序传递实际剩料

target_ref / requirements

原始 CAD / 最终要求、独立中间要求及所需外部资料

输出 / OUTPUT

result_geometry / material_states

实际加工实体/网格、数据格式、精度、材料来源及工序交接

metrics

体积 IoU、过切/欠切等几何指标及方法/精度

requirement_results

最终与中间要求分别返回通过、失败、未验证或不可判定

scope / coverage

计划工步、已执行/未执行及未验证项；整卡完成状态与局部结果分开

replay / provenance

实际加工状态、轨迹、NC/配置/结果版本与错误反馈

通用接口约定与完整定义
  • CAD 与制造要求的原始版本贯穿整条流程。
  • 文件引用包含版本与哈希；单位、坐标和刀长语义必须一致。
  • 工艺意图可来自人工结构化卡、未来 Agent 或经核对的纸质卡；与 CAM 执行方案分开建模。
  • 不支持、缺信息或精度不足时显式返回状态，不能自动视为通过。
  • 几何指标不代替粗糙度、材料物理、夹紧力或真实机床验证。
  • 模块2/3按明确适配接口扩展，执行前匹配整链能力，新增能力须通过新旧用例验收。
  • 外部纸质工艺卡保留原文、版次与字段位置，按有版本的字段和语义映射转为内部输入；缺项不得静默填默认值。
  • 加工参数逐项注明来自工艺卡、资源配置或程序/CAM推导；影响工艺路线或要求的修改返回规划端。
  • 原始最终要求与工序中间要求分开；外部通知单、缺项和冲突有来源、影响范围与处理方。
  • 执行前声明支持范围和必要前置条件，执行后报告工步与要求的覆盖；局部几何通过不等于整卡完成。
  • 历史 S1 参数记录保持不变，新的工艺意图/执行方案仅为接口设计，迁移和运行时校验待实现。
