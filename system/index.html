模块接口

设计定义 · 尚未全部实现为可执行适配器

几何识别

上游模块 · 接口定义

从零件视图重建 CAD，把尺寸、公差、粗糙度等要求关联到对应的面、边或特征。

输入 / INPUT

part_views

图像 / 图纸视图及其视向、来源与比例信息

context

单位、已知尺寸、可用材料标注等辅助信息

输出 / OUTPUT

cad_ref

原始 CAD 文件 / CadQuery 及对应导出几何，含版本、单位、坐标系、哈希

features

稳定的特征 ID 与当前 CAD 实体的映射

requirements

要求类型、数值、公差、单位、关联特征和来源标注

issues

识别歧义、缺失信息与待确认项

工艺规划

输入 / INPUT

加工编程

当前开发范围

把工艺卡映射成 CAM 任务，计算刀路，再按选定控制器规则导出最终 NC。

输入 / INPUT

process_card

有序工序、刀具、装夹、坐标与参数

cad_ref

原始 CAD；同一版本也传递给仿真验收

resource_profile

设备能力、NC 方言、毛坯、工具 / 夹具几何

输出 / OUTPUT

nc_ref

最终 NC 文件及其哈希、后处理器版本

machining_config

解析后的毛坯、刀具、坐标变换、控制器语义与夹具

provenance

工艺卡、CAD、CAM 软件与配置版本的绑定

issues

不支持工序、超出能力、单位或引用错误

展开接口示例 · JSON
{
  "schema": "genlaw.machining-job.v0",
  "job_id": "S1-JOB-01",
  "nc_ref": {
    "path": "reference.nc",
    "sha256": "<final NC hash>"
  },
  "target_ref": "target.step@s1-v1",
  "process_card_ref": "S1-TEST-v1",
  "machining_config_ref": "R-XYZ-01",
  "implementation": {
    "cam": "FreeCAD CAM",
    "postprocessor": "FreeCAD bundled linuxcnc_post",
    "linuxcnc_runtime_required": false
  }
}

仿真检验

当前开发范围

从真实声明的毛坯执行 NC，保存剩余材料，并在同一坐标系下与原始 CAD 比较。

输入 / INPUT

nc_ref

模块 2 导出的同一份最终 NC

machining_config

实际毛坯、刀具、装夹 / 坐标与所需控制器语义

target_ref / requirements

未经改写的目标 CAD 与制造要求

输出 / OUTPUT

result_geometry

实际加工后的实体 / 网格，注明数据格式

metrics

体积 IoU、过切 / 欠切等指标及计算方法 / 精度

requirement_results

逐项要求的通过、失败、未验证或不可判定状态

replay / provenance

保存的加工状态、轨迹、NC / 配置 / 结果哈希与错误反馈

展开接口示例 · JSON
{
  "schema": "genlaw.verification-result.v0",
  "job_id": "S1-JOB-01",
  "result_ref": "simulated.stl",
  "metrics": {
    "volume_iou": "<measured value>",
    "method": "<numeric method and resolution>"
  },
  "requirement_results": [
    {
      "id": "R_DIAMETER",
      "status": "not_verified"
    }
  ],
  "replay_ref": "frames.json",
  "physical_process_verified": false
}
通用接口约定与完整定义
  • CAD 与制造要求的原始版本贯穿整条流程。
  • 文件引用包含版本与哈希；单位、坐标和刀长语义必须一致。
  • 工艺卡可以来自固定测试输入、人工或未来的 Agent，使用同一接口。
  • 不支持、缺信息或精度不足时显式返回状态，不能自动视为通过。
  • 几何指标不代替粗糙度、材料物理、夹紧力或真实机床验证。

当前参考案例调用 FreeCAD 自带的 linuxcnc_post 导出 NC。它是后处理器名称；此链路没有安装或运行 LinuxCNC。
