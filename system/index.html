几何识别

暂缓开发

从零件视图重建 CAD，把尺寸、公差、粗糙度等要求关联到对应的面、边或特征。

输入

part_views

图像 / 图纸视图及其视向、来源与比例信息

context

单位、已知尺寸、可用材料标注等辅助信息

输出

cad_ref

原始 CAD 文件 / CadQuery 及对应导出几何，含版本、单位、坐标系、哈希

features

稳定的特征 ID 与当前 CAD 实体的映射

requirements

要求类型、数值、公差、单位、关联特征和来源标注

issues

识别歧义、缺失信息与待确认项

仿真检验

孔系 / 盲孔及反例已测

修补后的完整 CAMotics 执行最终 NC；比较原 CAD 与实际剩料，逐孔测量孔径、孔心和贯穿，错误可定位到具体孔。S1 / S2 均有正常与错误实例；制造验收待依据，粗糙度尚未测量。

输入

nc_ref / execution_plan

模块 4 的同一份最终 NC、工步关联、执行和检验范围

machining_config / incoming_state

实际来料、刀具、装夹/坐标与控制器语义；多工序传递实际剩料

target_ref / requirements

原始 CAD / 最终要求、独立中间要求及所需外部资料

输出

result_geometry / material_states

实际加工实体/网格、数据格式、精度、材料来源及工序交接

metrics

体积 IoU、过切/欠切等几何指标及方法/精度

requirement_results

最终与中间要求分别返回通过、失败、未验证或不可判定

scope / coverage

计划工步、已执行/未执行及未验证项；整卡完成状态与局部结果分开

replay / provenance

实际加工状态、轨迹、NC/配置/结果版本与错误反馈

feature_observations / software_regression

受限单孔逐项观测与独立软件测试条件；不将测试阈值写入制造要求

下载完整接口定义 ↓

参数由谁确定，缺项怎样处理？
  • 卡上明确规定：作为约束传递；修改须回到工艺规划或工艺师傅。
  • 资源提供：引用有版本的毛坯、设备、刀具、夹具及坐标配置。
  • 程序 / CAM 推导：记录依据、输入、规则或引擎版本；只能在已定义的工艺与能力范围内选择。
  • 无法确定：明确缺什么、影响哪步、交给谁处理；不得静默补默认值。

缺关键执行数据阻止对应 NC 生成；缺验收依据阻止对应质量判定。范围和前置条件必须明确，软件就绪与工艺批准分别记录。

工艺衔接定义 ↓

扩展与验收约定
  • 新尺寸/孔位等变体由数据驱动，主流程没有零件编号分支。
  • 新组合保持实际剩料连续，单位、坐标与要求绑定一致。
  • 不支持的工艺、设备语义或精度在执行前报告；检验不足时返回不可判定。
  • 新增能力通过小型独立正常/错误案例，同时保留旧能力的回归结果。
  • 工艺卡约束与派生参数来源可追溯；缺项和资料冲突在受影响阶段拦截，不复用历史案例默认值。
  • 工步与最终/中间要求分别报告；非几何或未支持步骤不被误计为整卡完成。

目标是将修改集中在适配器、配置和必要的版本演进，并用测试证明兼容；不承诺任何新零件都无需算法开发或永远无需调整公共接口。
