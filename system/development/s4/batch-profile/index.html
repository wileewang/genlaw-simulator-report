软件验收标准与输入存档

整料、P01、P02、余料各自 IoU ≥ 99%；轮廓偏差 ≤ 0.05 mm，保留平面偏差 ≤ 0.025 mm，并通过两阶积分稳定性检查。去料网格 0.025 mm，圆弧折线误差上限 0.0005 mm。工艺师傅尚未批准这些合成工艺卡。

距离真实生产还差什么

本组验证两个合成小产品，共用通用 XYZ、固定刀轴与 6061 材料标签。真实连接板的一坯 28 件、压板转换、切断后的零件运动及整张工艺卡尚未通过；本次没有新增机床型号或材料切削性能。
