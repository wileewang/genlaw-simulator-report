软件验收条件与输入存档

每步 IoU ≥ 99%；体积偏差 ≤ 0.15 mm³，包围盒及保留面偏差 ≤ 0.025 mm。圆角偏差限 0.15 mm、倒角偏差限 0.1 mm，使用 0.05 mm 数值保护带。最终检查 110 个圆角点、110 条倒角截线和 25 条保留面射线，并验证完整截面及积分稳定性。

这些是软件回归条件；PDF 工艺卡、参数及制造公差尚待工艺师傅批准。20 项输入、NC 与装夹错误检查通过。
