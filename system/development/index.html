下料、车削等工艺如何扩展？
  • 板材 / 型材下料：复用工艺卡、资源、状态与检验接口，补毛坯和切割工艺。
  • 车削 / 螺纹：复用流程与结果，新增编程和去料能力，以及对应特征验收。
  • 齿形 / 成形 / 其他工艺：按需求接入专用算法或引擎，并保留各自支持边界。

真实资料优先按简单独立单件选样；缺少覆盖某项能力的样本时，再构造小型补充用例。
