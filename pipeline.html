第二层 / 工艺规划

  1. 制定工艺

    零件与要求 + 资源↓候选工艺卡

    Agent 选择工序、资源和参数

    候选工艺卡↓已校验工艺卡 / 错误

    程序检查字段、参数和设备能力

第二层 / 加工编程

  1. 建立加工任务

    工艺卡 + CAD↓CAM Job（任务对象）

    我们的程序把工艺卡转成 CAM 任务

  2. 计算刀路

    CAM 任务↓内部刀路

    调用 CAM 后端；五轴联动工具待选型

  3. 生成设备代码

    内部刀路 + 控制器配置↓最终 G-code

    设备后处理器转换指令格式

当前待做先开发 FreeCAD CAM 适配与 NC / 配置导出，验证固定刀轴后处理；连续五轴另行选型。

03

仿真检验

检查加工后的几何是否合格

输入
G-code + 加工配置 + 实际毛坯对照原始 CAD 与制造要求
输出
几何检验报告 + 回放合格与否、差异位置、已有的过程记录
实现方式
仿真引擎去料，程序比较几何
展开第二层收起第二层＋

第二层 / 仿真检验

  1. 执行加工仿真

    G-code + 来料 + 加工配置↓剩余材料 + 执行记录

    程序准备输入，调用支持该工序的仿真引擎

  2. 比较几何

    剩余材料 / 记录 + 原始 CAD / 要求↓几何验收结果

    程序检查执行完整性、过切、欠切与公差

  3. 展示结果

    验收结果 + 保存的过程记录↓报告 + 可用过程回放

    展示程序与 Anatomy

当前待做固定刀轴先评估 CAMotics，接入原始 CAD / 公差验收与回放；LinuxCNC 可另验机床运动，不能替代去料与几何验收。

共同资料

原料、设备、刀具、夹具资料；原始 CAD 与制造要求贯穿全程。

↶ 检验失败：把原因返回工艺规划，调整后重新生成代码并检验。
