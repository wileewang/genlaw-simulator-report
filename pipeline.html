01

几何与要求绑定

待上游补齐
输入D0：CadQuery / CAD + 制造要求

孔、面、基准及公差 / 粗糙度标注

内部实现上游模型 + 校验程序模型判断每条要求对应哪个特征

程序校验引用、模型版本和单位

输出D1：零件输入包

CAD + 特征 ID + 已绑定的要求

展开：字段、异常与待开发项

输出包括

  • 模型引用与版本、单位、坐标
  • features：特征 ID 与几何引用
  • requirements：要求 ID、特征 ID、公差、基准、粗糙度

失败时

无法唯一关联的标注返回待确认，不能编造绑定。

需要开发

增加稳定特征引用、绑定输出及独立校验。

02

工艺规划 Agent

待开发
输入D1：零件输入包 + R：资源档案

可用原料、设备、刀具和夹具

内部实现模型 / Agent选择毛坯、装夹、工序顺序

选择刀具、余量、进给和转速

输出D2：工艺卡 JSON

有序工序及各工序的资源和参数

展开：字段、异常与待开发项

输出包括

  • plan_id / version、源模型版本
  • 毛坯、设备、装夹及工件坐标
  • operations：工序、特征 ID、刀具 ID、参数、要求 ID

失败时

资源或工艺信息不足时输出缺项；此阶段结果尚未通过程序校验。

需要开发

开发工艺 Agent、工艺卡规范及资源查询工具。

03

工艺卡校验

有局部规则，需统一
输入D2：工艺卡 + D1：原始要求

R：设备、刀具、夹具及能力约束

内部实现我们写的规则程序检查字段、引用、单位与参数范围

检查选定设备是否支持这些工序

输出D3：已校验工艺卡

或：错误清单 → 工艺 Agent

展开：字段、异常与待开发项

输出包括

  • 冻结的工艺卡及其版本
  • 校验所用资源版本、检查结果
  • errors：工序 ID、字段、错误代码、原因

失败时

校验失败时不进入 CAM；字段和能力检查通过不等于制造已经合格。

需要开发

统一 Schema、引用、参数与能力校验，形成可回传错误。

04

CAM 任务转换

待开发 / 接入
输入D3：已校验工艺卡 + 原始 CAD

R：刀具、设备及装夹参数

内部实现我们写的 Python 程序把工序映射成 FreeCAD 操作对象

创建 Job、工具与坐标设置

输出D4：FreeCAD CAM Job

模型、毛坯、工具、操作的任务对象

展开：字段、异常与待开发项

输出包括

  • 模型 / 毛坯引用、装夹坐标
  • 工具控制器、切削参数、操作顺序
  • 特征引用与操作参数

失败时

未支持的工序或失效的几何引用必须拒绝。

需要开发

实现工艺卡到 FreeCAD Job 的映射与版本适配；转换程序本身不计算刀路。

05

刀路计算

软件现成，待集成
输入D4：CAM Job

已选定的模型、刀具、工序和参数

内部实现现成软件：FreeCAD CAM调用 FreeCAD 的加工算法

计算切削路径及进退刀等移动

输出D5：FreeCAD 内部刀路

移动、进给、转速等内部命令

展开：字段、异常与待开发项

输出包括

  • 各操作的 Path 命令
  • 移动路径、进给、转速及工具等信息

失败时

刀路生成失败时保留日志并终止该次生成。

需要开发

接入并验证所选版本和工序的自动调用，不重写其刀路算法。

06

设备后处理

需按控制器验证
输入D5：内部刀路 + 目标控制器配置

单位、工件坐标、刀补与换刀约定

内部实现现成后处理程序 + 设备适配按控制器方言转换和格式化命令

生成程序起止、换刀等指令

输出D6：最终 G-code 文件

附控制器、后处理器与配置版本

展开：字段、异常与待开发项

输出包括

  • program.nc 的引用与哈希
  • 控制器方言、后处理器及其版本
  • 所用机床 / 坐标 / 刀具配置引用

失败时

缺少适配后处理器或遇到不支持的命令时，不能声称可上机。

需要开发

选择或修改后处理器，验证目标控制器语义。

07

仿真输入准备

有局部接口，需扩展
输入D6：最终 NC + 实际来料几何

刀具、夹具、坐标、方言与精度

内部实现我们写的适配程序检查后端是否支持本次输入

转换配置并组装完整仿真作业

输出D7：仿真作业包

NC、来料、工具及后端执行配置

展开：字段、异常与待开发项

输出包括

  • 最终 NC 与实际毛坯 / 上道工序材料引用
  • 工具、夹具、坐标变换和控制器方言
  • 后端版本、精度、请求的检查及支持范围

失败时

不支持的来料或指令需拒绝或列为未验证，不能用目标零件替代来料。

需要开发

统一后端接口，适配实际材料、坐标与指令支持。

08

NC 去料仿真

外部仅小控制验证
输入D7：仿真作业包

本后端已支持的 NC、来料和刀具

内部实现仿真引擎，如 CAMotics解释最终 NC 并执行对应运动

计算工具运动造成的材料去除

输出D8：仿真结果包

剩余材料、执行记录、错误与精度

展开：字段、异常与待开发项

输出包括

  • 最终剩余材料几何
  • 执行完成标志、错误、未支持指令
  • 分辨率及后端支持的轨迹 / 中间状态；缺项显式记录

失败时

未完整执行或所需检查不受支持，必须向后续验收报告。

需要开发

完成客户工序 / 整件对照；由适配程序归一化结果，不假设所有后端都输出完整轨迹。

09

几何验收

有基础，需按公差扩展
输入D8：剩余材料与执行记录

B：只读原目标、基准和公差

内部实现我们写的几何比较程序先检查执行完整性与计算精度

再检查过切、欠切、尺寸和位置

输出D9：逐项几何验收报告

通过 / 不通过 / 不可判定及证据

展开：字段、异常与待开发项

输出包括

  • 要求 ID、实测值、允许范围、计算误差
  • 过切 / 欠切位置与差异几何
  • 未验证要求；粗糙度不由纯几何仿真判定

失败时

失败证据回传规划环节；精度不足返回不可判定，不能修改原始公差使结果通过。

需要开发

补按特征公差验收、精度判定和结构化失败证据。

10

报告与回放

已有基础，需接新结果
输入D8：材料状态 / 轨迹 + D9：验收

工艺卡与本次运行记录

内部实现展示程序 + Anatomy组织报告、差异位置和过程视图

展示后端实际保存的状态

输出D10：网页报告 / 动画

可查看、定位和追溯的运行结果

展开：字段、异常与待开发项

输出包括

  • 验收报告页面、差异视图
  • 材料状态、轨迹与工序的对应关系

失败时

缺少中间状态时明确显示可用范围，不补画成已执行过程。

需要开发

把新 CAM / 仿真后端的结果接到已有报告和回放。

三个支撑模块

给主流程提供资源、独立验收基准与调用控制。

A

资源档案

有参考配置，需统一
输入工厂设备、刀具、夹具及原料资料

工艺规则与适用范围

内部实现配置 / 数据库 + 查询程序保存版本、单位、能力和限制

按 ID 查询并解析所需资源

输出R：版本化的资源记录

供规划、校验、CAM 与仿真读取

展开：字段、异常与待开发项

输出包括

  • machine / controller / tool / fixture / stock / rules

失败时

资料缺失要显式返回，不能从零件几何推断出真实设备。

需要开发

统一资源类型与查询接口；区分参考配置和实际设备资料。

B

原始验收基准

有原目标保留，需扩展
输入上游已校验的 D1 零件输入包

原始 CAD、基准与绑定要求

内部实现只读存储与版本管理程序固定模型版本、引用与哈希

让后续验收独立读取原始要求

输出B：不可由工艺 Agent 改写的快照

目标几何 + 公差 / 基准 / 要求

展开：字段、异常与待开发项

输出包括

  • 源模型版本、目标几何引用、原始要求及绑定

失败时

版本不一致时拒绝比较，要求变更应创建新的上游版本。

需要开发

将原始几何与语义制造要求绑定为统一验收快照。

C

任务编排与回传

有限定路线，需通用化
输入任务请求、各模块状态与错误

工艺卡、仿真和验收结果

内部实现我们写的流程控制程序按依赖调用、传递结果、记录版本

遇错停止；按错误类型反馈重试

输出运行记录 / 停止原因 / 修改请求

可修正的工艺问题返回 Agent

展开：字段、异常与待开发项

输出包括

  • run_id、输入与代码 / 配置版本、每步状态、日志
  • 失败阶段、错误代码、特征 / 工序 ID、证据、重试上限

失败时

绑定问题回上游，工艺问题回规划；不能无限重试或悄悄放宽验收标准。

需要开发

统一任务状态、错误路由、重试策略和全链记录。
